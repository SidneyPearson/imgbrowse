# 🖼 imgbrowse — macOS 本地图片丝滑浏览工具

一个零依赖的单文件小工具：在本机起一个轻量 Web 服务，用浏览器流畅浏览本地大图/视频。
专为**手机原图、单张几 MB、一个文件夹几百张**的场景设计——缩略图分级缓存、分页加载、灯箱预加载，翻页零等待。

## 特点

- **零依赖**：只用 macOS 自带的 Python 3 和系统工具（`sips` / `qlmanage`），`imgbrowse.py` 单文件拷走就能跑
- **两级浏览**：封面墙（每个文件夹一张封面）→ 分页网格 → 灯箱大图，不会一次性铺几千张图
- **丝滑加载**：缩略图 / 网格图 / 封面 / 屏显图四级派生缓存；灯箱模糊占位（blur-up）+ 前后各 2 张预加载
- **视频支持**：`.mp4 / .mov / .m4v …` 自动抽帧做缩略图，灯箱内直接播放（支持拖动进度）
- **整理功能**：移动图片到其他文件夹（快捷键 M / 拖拽到侧栏）、重命名文件夹、删除到**废纸篓**（可恢复）
- **收藏 ⭐**：标星的图片汇入「我的收藏」虚拟相册，按文件指纹持久化，移动/改名/重启都不丢
- **自定义封面**：任意图片右键即可设为文件夹封面
- **图片信息**：EXIF 面板（分辨率、拍摄时间、相机、快门/光圈/ISO/焦距、视频时长），按 `I`
- **幻灯片**：可调速（2/3/5/8s）、随机顺序、Ken Burns 缓推效果
- **记忆位置**：每个文件夹自动记住上次看到的页码
- **网格密度**三档切换；`?` 查看全部快捷键

## 快速开始

```bash
# 浏览指定目录（启动后自动打开浏览器）
python3 imgbrowse.py ~/Pictures

# 或浏览当前目录
python3 imgbrowse.py

# 指定端口 / 不自动开浏览器
python3 imgbrowse.py ~/Photos --port 9000 --no-open
```

macOS 双击用法：把 `浏览图片.command` 放在 `imgbrowse.py` 旁边，双击即可（默认浏览 `~/Pictures`，
目录不存在时可把文件夹拖到终端窗口里）。也可以在界面左上角「📁 打开文件夹」随时切换任意目录。

要求：macOS + Python 3.9+（macOS 自带）。

## 常用快捷键

| 按键 | 功能 |
|---|---|
| `←` / `→` / `空格` | 灯箱上一张 / 下一张 |
| `↑` / `↓` / `PgUp` / `PgDn` | 网格翻页（触控板双指上下滑动亦可） |
| `Enter` | 打开当前页首图 |
| `Esc` | 关闭灯箱 / 取消选择 / 返回 |
| `⌫` (Delete) | 删除（移到废纸篓） |
| `M` | 移动图片 |
| `.` | 收藏 / 取消收藏 |
| `I` | 图片信息面板 |
| `S` | 幻灯片播放 / 暂停 |
| `F` | 全屏 |
| `?` | 快捷键速查 |
| `B` | 收起 / 展开侧栏 |

网格中：点击 ✓ 或 Shift+点击 批量选择，右键弹出菜单，拖拽图片到侧栏文件夹即可移动。
灯箱中双击图片可在「适应窗口 / 原图 1:1」之间切换，滚轮缩放、拖拽平移。

## 工作原理

- Python 标准库 `ThreadingHTTPServer` 提供接口与图片服务（支持 HTTP Range，视频可拖动）
- 用 macOS 自带 `sips` 生成 JPEG 派生图（信号量限制并发，避免吃满内存），视频用 `qlmanage` 抽帧
- 缓存位于 `~/Library/Caches/imgbrowse/`，key = 绝对路径 + mtime + size 的哈希，源图变动自动失效
- 收藏 / 自定义封面保存在 `~/Library/Application Support/imgbrowse/state.json`，按文件指纹记录

## 说明

- 所有文件操作都限制在你打开的根目录内；删除走 Finder 废纸篓，可随时恢复
- 工具不会上传任何文件，服务只监听 `127.0.0.1`，纯本地运行
